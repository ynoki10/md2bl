# Security Policy

## Supported Versions

Only the latest version is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest | :x:               |

## Scope

md2bl is a text transformation tool that converts Markdown to Backlog notation. It:

- Reads local files or stdin
- Does **not** access the network
- Does **not** execute dynamic code (`eval`, `Function`, etc.)
- Does **not** interact with databases or external services

## Reporting a Vulnerability

Please report security vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/ynoki10/md2bl/security/advisories/new).

**Do not** report security vulnerabilities through public GitHub issues.

### What to expect

- I will acknowledge your report within **7 days**
- I will provide an estimated timeline for a fix
- I will notify you when the vulnerability is fixed

Thank you for helping keep md2bl safe.
