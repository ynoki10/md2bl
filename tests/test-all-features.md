## コードブロック

言語指定なし:

```

console.log(message);
```

Java（対応言語）:

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

C#（対応言語）:

```cs
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }

```

```typescript

const greet = (user: User): string => {
  return `Hello, ${user.name}!`;
};
```

## 複合的なテスト

以下は複数の要素を組み合わせた実践的なドキュメントの例です。

### プロジェクト概要

このプロジェクトは**Markdown**から**Backlog記法**への変換ツールです。主な機能は以下の通りです:

1. ファイル入力またはstdinからの読み込み
2. [unified](https://unifiedjs.com/) を使ったASTパース
3. 再帰的なノード変換

> **注意:** 一部の記法は未対応です。詳細は[ドキュメント](https://example.com/docs)を参照してください。

### インストール手順

```
npm install -g md2bl
```

| コマンド | 説明 |
| --- | --- |
| `md2bl input.md` | ファイルを変換 |
| `cat input.md \| md2bl` | stdinから変換 |
